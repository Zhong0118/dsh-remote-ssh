**Architecture:** Keep the existing transport/routers; adjust the bundle to the new agent-preset lifecycle, bind session routes without global tool assumptions, migrate the Plugins tab slot, and rebuild against matching DSH packages. Validate the actual profile and browser rather than relying only on mocked tests.

**Tech Stack:** TypeScript, Cordis, DSH packages `0.1.7-rc.2`, pnpm, Vitest, React, YAML.

**Spec:** `docs/superpowers/specs/2026-09-28-dsh-017-compat-design.md`

## Global Constraints

- Preserve SSH config/keys, remote files, workspace and Session history, existing profile dependencies/patches, and `.dsh-meow/`.
- Keep fail-closed routing, Web-only client, unchanged native tool names, POSIX/Linux remote and Windows host support.
- No SSH host supplied: real remote execution remains untested.
- Do not modify DSH checkout or start a replacement Web server.
- Existing Web profile does not currently install the plugin; install from `github:Zhong0118/dsh-remote-ssh#web-dsh-rc8` after pushing.
